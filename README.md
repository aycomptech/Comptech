# CompTech — GitHub Pages
Website statis untuk service komputer/laptop, smartphone, CCTV, internet dan jaringan.

## Upload
Upload seluruh isi folder ini ke repository GitHub. `index.html` harus berada di root.
Aktifkan **Settings → Pages → Deploy from a branch → main → /root**.

## WhatsApp
Edit `script.js`, lalu ubah `6281234567890` menjadi nomor WhatsApp CompTech.
