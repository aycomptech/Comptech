# TechFix Service Website

Website landing page statis untuk service komputer, laptop, HP, upgrade, software, dan jaringan.

## Upload ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload seluruh isi folder ini.
3. Settings -> Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: / (root).
6. Save.

## Ganti nomor WhatsApp
Cari `6281234567890` di `index.html` lalu ganti dengan nomor WhatsApp Anda (format internasional, tanpa + dan tanpa 0 di depan).
